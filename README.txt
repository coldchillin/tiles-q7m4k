Singapore Mahjong Coach - offline home-screen app

Upload every file in this folder (not the folder itself) to the root of a GitHub repository,
then turn on GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).
Open https://YOUR-USERNAME.github.io/REPO-NAME/ in Safari, then Share > Add to Home Screen.
Open it once while online so it saves itself for offline use.

To update the game later, upload a new index.html over the old one. The app picks it up
the next time it is opened with a connection.
